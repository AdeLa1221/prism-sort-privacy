# Prism Sort — Privacy Policy

Official Privacy Policy & Data Safety landing page for the mobile game **Prism Sort** (`com.kizgiydiroyun.prismsort`).

Published via GitHub Pages at: [https://adela1221.github.io/prism-sort-privacy/](https://adela1221.github.io/prism-sort-privacy/)

## Highlights
- **100% Offline & Standalone:** No internet connectivity required.
- **Zero Data Collection:** No personal data, device identifiers, or analytics tracked.
- **No Third-Party SDKs:** No ads (AdMob, Unity Ads) or tracking platforms (Google Analytics, Firebase).
- **Local Storage Only:** Game progress is saved exclusively on the local device.
- **Languages Included:** Turkish (TR), English (EN), German (DE), Spanish (ES), Portuguese - Brazil (PT-BR).
